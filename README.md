# customer_behavior_analysis
End-to-end Customer Shopping Behaviour Analytics project using Python, PostgreSQL, SQL, and Power BI to clean, analyze, and visualize customer purchasing patterns and business insights.

## Project Overview
This project focuses on analyzing customer shopping behaviour to identify purchasing patterns, customer preferences, and business insights. It uses Python for data cleaning and exploratory data analysis, PostgreSQL for querying and analysis, and Power BI for interactive data visualization.

## Dataset
- Dataset: Customer Shopping Behaviour
- Records: 120 customer records
- Original Features: 18 columns
- Includes customer demographics, product categories, purchase amounts, discounts, shipping methods, subscription status, and review ratings.

## Tools & Technologies
- **Python:** Data cleaning and Exploratory Data Analysis (EDA)
- **Pandas:** Data manipulation and preprocessing
- **Jupyter Notebook:** Python development environment
- **PostgreSQL:** Database management and SQL analysis
- **Power BI:** Interactive dashboard development
- **GitHub:** Project documentation and version control

## Project Workflow

### 1. Data Loading
Imported the customer shopping behaviour dataset into Python using Pandas.

### 2. Data Cleaning & EDA
- Identified and handled missing values using category-wise median imputation.
- Standardized column names.
- Removed redundant columns.
- Created age groups using quantile-based segmentation.
- Converted purchase frequency into numerical day values.
- Explored customer and purchasing patterns.

### 3. SQL Analysis
Loaded the cleaned dataset into PostgreSQL and performed business analysis using SQL queries, including:
- Revenue generated by gender.
- Discount usage and customer spending.
- Top-rated products.
- Shipping type comparison.
- Subscription status and spending patterns.
- Product discount rates.
- Customer segmentation.
- Top-selling products by category.
- Repeat buyer analysis.
- Revenue by age group.

### 4. Power BI Dashboard
Developed an interactive dashboard to visualize customer behaviour and key business metrics using charts, cards, and filters.

## Key Business Questions
- Which customer groups generate the highest revenue?
- Do subscribed customers spend more?
- Which products receive the highest ratings?
- How do shipping methods influence purchase amounts?
- Which customer segments contribute to business revenue?

## How to Run the Project

1. Clone this repository.
2. Install Python and the required libraries (`pandas`, `sqlalchemy`, `psycopg2-binary`).
3. Open the Jupyter Notebook and load the customer shopping behaviour CSV dataset.
4. Execute the notebook cells to perform data cleaning and preprocessing.
5. Create a PostgreSQL database named `customer_behavior`.
6. Connect Python to PostgreSQL and load the cleaned dataset.
7. Execute the SQL queries using pgAdmin.
8. Open the `.pbix` file in Power BI Desktop to explore the dashboard.
